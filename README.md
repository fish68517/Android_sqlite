# SenseCheck - Android 单机版无感签到

这是按照根目录《Android单机版无感签到开发方案.md》实现的 Java Android 课程项目。项目不依赖服务器、MySQL、Spring Boot 或 Vue，所有配置和签到记录均保存在手机本地。

## 已实现功能

- 学号、姓名、专业班级和本机设备编号。
- 单门课程的星期、上课时间、教室坐标、允许距离和采集间隔配置。
- 手动测试签到。
- 前台服务在课程时间内按间隔自动签到。
- AlarmManager 保存下次课程启动计划，设备重启后重新安排。
- 定位、Wi-Fi、BLE 蓝牙和 Wi-Fi Direct 数量采集。
- 按时间、距离和周边环境执行“成功/证据不足/失败”判断。
- SQLite 本地签到记录、历史列表、详情和成功率统计。
- CSV/JSON 文件导出，以及通过系统应用分享 CSV 文本。
- Android 版本相关的定位、蓝牙、附近 Wi-Fi 和通知权限申请。

## 项目结构

```text
SenseCheck/
├─ app/src/main/java/com/example/sensecheck/
│  ├─ checkin/   # 环境采集、签到协调和判断规则
│  ├─ data/      # SharedPreferences、SQLite 和数据对象
│  ├─ receiver/  # 课程闹钟和开机恢复
│  ├─ service/   # 前台自动签到服务
│  ├─ ui/        # 首页、设置、历史和详情页面
│  └─ util/      # 时间、权限、导出和课程调度工具
├─ app/src/main/res/             # XML 页面、颜色、样式和图标
└─ app/src/main/AndroidManifest.xml
```

## 在 Android Studio 中打开

1. 使用 Android Studio 打开本目录 `SenseCheck`。
2. 确认 JDK 选择 17。
3. 确认已安装 Android SDK 34；若只安装了其他版本，可同时修改 `app/build.gradle` 中的 `compileSdk` 和 `targetSdk`。
4. 等待 Gradle Sync 完成。
5. 连接 Android 8.0 或以上真机。
6. 由你在 Android Studio 中自行构建和安装 APK。

项目包名为 `com.example.sensecheck`，当前版本为 `1.0`。

## 推荐测试顺序

1. 打开“个人信息设置”，填写学号和姓名。
2. 打开“课程设置”，选择当前星期，把课程开始/结束时间设置为当前时间附近。
3. 点击“使用当前位置作为教室位置”，允许定位权限。
4. 调试时把间隔设为 1 分钟并开启自动签到。
5. 回到首页点击“检查并申请权限”。
6. 点击“立即测试签到”，等待约 6 秒。
7. 在“签到历史与导出”中查看记录详情并导出 CSV/JSON。
8. 在课程时间内点击“启动自动签到服务”，把 APP 切到后台，观察通知和后续记录。
9. 最终报告和视频中把间隔说明为约 15 分钟；1 分钟仅用于 Debug 演示。

## 已知边界

- 现代 Android 会限制或随机化 MAC 地址，本项目只统计系统实际允许发现的 Wi-Fi、BLE 和 Wi-Fi Direct 设备数量，不承诺得到真实固定 MAC。
- 自动签到依赖用户授予定位、附近设备和通知权限，并可能受不同厂商的省电策略影响。
- AlarmManager 使用非精确唤醒，不保证在课程开始的某一秒执行。
- 本项目不包含服务器集中汇总、多手机实时合并、正式身份认证或复杂反作弊。
- 分享功能直接分享 CSV 文本；需要正式附件时，请先使用“导出 CSV”保存文件，再在邮箱或其他应用中选择该文件。

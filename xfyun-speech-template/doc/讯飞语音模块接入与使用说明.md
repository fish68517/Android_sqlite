# 讯飞语音模块接入与使用说明

本文档用于说明 `xfyun-speech-template` 模块如何快速接入到其他 Android 项目，以及接入后的基本使用方式。

适用对象：

- 需要把当前项目中的讯飞语音能力迁移到其他项目
- 希望按“即插即用”的方式集成语音识别模块
- 使用讯飞 Android 语音听写 SDK 的场景

## 1. 模块说明

当前模块路径：

```text
Android/xfyun-speech-template
```

当前模块封装的是“讯飞语音听写识别”能力，核心对外类如下：

- `XfYunSpeechConfig`：模块配置
- `XfYunSpeechModule`：模块初始化入口
- `XfYunSpeechRecognizer`：语音识别调用入口
- `XfYunSpeechListener`：识别回调接口
- `XfYunSpeechResultParser`：识别结果 JSON 解析器

当前模块职责比较单一，适合直接复制到其他项目中复用。

## 2. 接入前需要准备的内容

在目标项目中接入本模块前，需要准备讯飞官方 Android SDK 文件。

需要放入模块内的文件如下：

1. `Msc.jar`
2. `libmsc.so` 等 native 动态库
3. `assets/iflytek` 资源目录

对应目录如下：

```text
xfyun-speech-template/
├─ libs/
│  └─ Msc.jar
├─ src/main/jniLibs/
│  ├─ armeabi-v7a/
│  │  └─ libmsc.so
│  └─ arm64-v8a/
│     └─ libmsc.so
└─ src/main/assets/
   └─ iflytek/
```

如果你拿到的是讯飞官方完整 SDK 包，通常把其中对应文件按上面的目录放好即可。

## 3. 如何接入到其他项目

### 3.1 复制模块

把整个模块目录复制到目标 Android 工程中，例如：

```text
your-project/
└─ speech-xfyun/
```

建议复制后将目录名改为更通用的名字，例如：

```text
speech-xfyun
```

这样在其他项目里更容易理解模块职责。

### 3.2 在 `settings.gradle` 中注册模块

例如模块目录名为 `speech-xfyun`，则在目标项目的 `settings.gradle` 中增加：

```groovy
include ':speech-xfyun'
```

如果你把它放在多级目录下，则按实际路径声明，例如：

```groovy
include ':core:speech-xfyun'
```

### 3.3 在业务模块中添加依赖

通常是在 `app/build.gradle` 中加入：

```groovy
implementation project(':speech-xfyun')
```

如果是多级模块，则按你的实际模块名引用：

```groovy
implementation project(':core:speech-xfyun')
```

### 3.4 确认模块内部依赖

当前模块的 `build.gradle` 已包含以下核心依赖：

```groovy
implementation 'androidx.core:core-ktx:1.12.0'
implementation files('libs/Msc.jar')
```

并且已经配置：

- `jniLibs.srcDirs = ['src/main/jniLibs']`
- `assets.srcDirs = ['src/main/assets']`

因此只要官方 SDK 文件放置正确，一般不需要额外改 Gradle。

## 4. 权限说明

模块 `AndroidManifest.xml` 中已经声明了以下权限：

- `android.permission.INTERNET`
- `android.permission.ACCESS_NETWORK_STATE`
- `android.permission.RECORD_AUDIO`
- `android.permission.MODIFY_AUDIO_SETTINGS`
- `android.permission.WRITE_EXTERNAL_STORAGE`
- `android.permission.READ_PHONE_STATE`

注意：

1. Android 6.0 及以上仍然需要在运行时动态申请 `RECORD_AUDIO`
2. 如果目标项目已经统一管理权限，按目标项目的权限框架处理即可

最关键的是保证录音权限已授权，否则语音识别无法正常启动。

## 5. 初始化方式

本模块初始化入口为：

```kotlin
XfYunSpeechModule.initialize(context, config)
```

配置对象：

```kotlin
val config = XfYunSpeechConfig(
    appId = "你的讯飞APPID"
)
```

完整初始化示例：

```kotlin
class App : Application() {
    override fun onCreate() {
        super.onCreate()

        XfYunSpeechModule.initialize(
            context = this,
            config = XfYunSpeechConfig(
                appId = "你的讯飞APPID"
            )
        )
    }
}
```

说明：

- 当前模块初始化底层使用的是 `SpeechUtility.createUtility(...)`
- 这一版封装主要依赖 `appId`
- `initialize()` 内部已经做了幂等处理，重复调用不会重复初始化

## 6. 配置项说明

`XfYunSpeechConfig` 当前字段如下：

```kotlin
data class XfYunSpeechConfig(
    val appId: String,
    val language: String = "zh_cn",
    val accent: String = "mandarin",
    val domain: String = "iat",
    val vadBos: String = "4000",
    val vadEos: String = "1000",
    val asrPtt: String = "1"
)
```

字段含义可按下面理解：

- `appId`：讯飞开放平台应用的 APPID
- `language`：识别语言，默认中文
- `accent`：方言或口音，默认普通话
- `domain`：识别领域，默认 `iat`
- `vadBos`：前端点超时
- `vadEos`：后端点超时
- `asrPtt`：是否加标点

一般情况下，接入其他项目时只改 `appId` 就可以先跑通。

## 7. 如何开始语音识别

### 7.1 创建识别器

```kotlin
val recognizer = XfYunSpeechRecognizer(
    context = this,
    config = XfYunSpeechConfig(
        appId = "你的讯飞APPID"
    )
)
```

### 7.2 启动识别

```kotlin
recognizer.startListening(object : XfYunSpeechListener {
    override fun onReady() {
        // 已完成参数设置，准备开始识别
    }

    override fun onPartialResult(text: String) {
        // 处理中间识别结果
    }

    override fun onFinalResult(text: String) {
        // 最终识别结果
    }

    override fun onError(code: Int, message: String) {
        // 错误处理
    }

    override fun onVolumeChanged(volume: Int) {
        // 音量回调，可用于 UI 动画
    }
})
```

### 7.3 停止识别 / 取消识别 / 释放资源

```kotlin
recognizer.stopListening()
recognizer.cancel()
recognizer.release()
```

建议：

- 用户主动结束说话时调用 `stopListening()`
- 页面退出或对象销毁时调用 `release()`
- 中断当前识别任务时调用 `cancel()`

## 8. 推荐使用方式

建议在页面或业务控制器中按下面顺序使用：

1. 应用启动时初始化模块
2. 页面进入后检查并申请录音权限
3. 创建 `XfYunSpeechRecognizer`
4. 用户点击“开始录音”后调用 `startListening()`
5. 在 `onPartialResult()` 中更新实时字幕
6. 在 `onFinalResult()` 中提交最终文本
7. 页面销毁时调用 `release()`

## 9. 最小可运行示例

下面给出一个更接近实际业务的最小示例：

```kotlin
class VoiceActivity : AppCompatActivity() {

    private lateinit var recognizer: XfYunSpeechRecognizer

    override fun onCreate(savedInstanceState: Bundle?) {
        super.onCreate(savedInstanceState)

        XfYunSpeechModule.initialize(
            context = applicationContext,
            config = XfYunSpeechConfig(
                appId = "你的讯飞APPID"
            )
        )

        recognizer = XfYunSpeechRecognizer(
            context = this,
            config = XfYunSpeechConfig(
                appId = "你的讯飞APPID"
            )
        )
    }

    private fun startVoiceInput() {
        recognizer.startListening(object : XfYunSpeechListener {
            override fun onReady() {
            }

            override fun onPartialResult(text: String) {
                // 实时展示识别文本
            }

            override fun onFinalResult(text: String) {
                // 使用最终文本
            }

            override fun onError(code: Int, message: String) {
                // 展示错误信息
            }

            override fun onVolumeChanged(volume: Int) {
                // 更新音量 UI
            }
        })
    }

    override fun onDestroy() {
        recognizer.release()
        super.onDestroy()
    }
}
```

## 10. 常见问题

### 10.1 提示“讯飞语音模块尚未初始化”

原因：

- 在调用 `startListening()` 之前没有执行 `XfYunSpeechModule.initialize(...)`

处理方式：

- 把初始化提前到 `Application` 或首次使用前

### 10.2 提示无法创建识别器或启动失败

优先检查以下内容：

1. `Msc.jar` 是否已放到 `libs/`
2. `libmsc.so` 是否已放到 `src/main/jniLibs/`
3. `assets/iflytek` 是否已放到 `src/main/assets/`
4. `APPID` 是否正确
5. 录音权限是否已授权

### 10.3 有权限但识别仍然无结果

优先排查：

1. 网络是否可用
2. 讯飞应用配置是否与当前 SDK 能力匹配
3. `language`、`accent`、`domain` 是否传错

## 11. 模块当前边界

当前 `xfyun-speech-template` 模块主要提供：

- 讯飞 SDK 初始化
- 语音听写识别
- 中间结果和最终结果回调
- 识别结果 JSON 解析

当前不包含：

- 完整 UI 页面
- 权限申请页面
- 业务层状态管理
- TTS 语音播报封装
- WebSocket 实时转写链路

因此在其他项目中接入时，建议把它作为“语音识别基础能力模块”，由业务层自己承接 UI、权限和状态管理。

## 12. 建议的接入清单

为了最快接入其他项目，建议按下面清单执行：

1. 复制 `xfyun-speech-template` 模块到目标项目
2. 改模块名，例如改成 `speech-xfyun`
3. 在 `settings.gradle` 注册模块
4. 在 `app/build.gradle` 添加 `implementation project(...)`
5. 放入 `Msc.jar`、`libmsc.so`、`assets/iflytek`
6. 在 `Application` 中调用 `XfYunSpeechModule.initialize(...)`
7. 在页面中申请 `RECORD_AUDIO` 权限
8. 创建 `XfYunSpeechRecognizer`
9. 调用 `startListening()` 并处理结果回调
10. 页面销毁时调用 `release()`

按以上步骤，一般就可以把当前模块快速迁移到新的 Android 项目中。

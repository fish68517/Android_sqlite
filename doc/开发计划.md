# 基于 Android 的日记系统开发计划

## 1. 开发目标

在 Android Studio 中使用 Java 完成一个本地运行的日记系统。系统以用户端为核心，使用 Android 本地 SQLite 保存数据，通过 `SQLiteOpenHelper` 完成数据库建表、升级和增删改查封装，不使用 Room，不开发管理员端，不依赖服务器。

本计划依据开题报告中的系统方向进行调整，去除管理员管理、后台统计、云同步、Web 后台等不符合当前实现条件的内容，保留适合毕业设计演示的用户端核心功能。

## 2. 技术路线

- 开发工具：Android Studio。
- 开发语言：Java。
- UI 技术：XML 布局、Activity、Fragment、RecyclerView、ViewBinding。
- 数据库：Android 本地 SQLite。
- 数据库封装：继承 `SQLiteOpenHelper`，自定义 DAO 或 Repository 类。
- 本地配置：`SharedPreferences` 保存登录状态和用户设置。
- 图片处理：保存图片本地路径，不将图片二进制直接写入 SQLite。
- 构建工具：Gradle 8.2，优先使用项目根目录 `downloads` 下的本地 Gradle 资源。

当前本地环境检查结果：

- `downloads/gradle-8.2-bin.zip` 文件存在，但大小只有 134 字节，当前不是有效 zip 包。
- `downloads/gradle-8.2` 目录存在，但部分 jar 文件大小异常，开发前需要确认是否为完整 Gradle 解压目录。
- 开发前应先补齐有效的 Gradle 8.2 本地包，或确认可直接使用 `downloads/gradle-8.2/bin/gradle.bat`。
- `gradle/wrapper/gradle-wrapper.properties` 当前仍指向网络 Gradle 8.5，需要改为本地 Gradle 8.2 路径后再作为最终环境。

## 5. 核心验收用例

### 用例一：注册登录

- 输入合法用户名、密码、邮箱。
- 注册成功后跳转登录。
- 输入正确用户名和密码。
- 登录成功后进入主页面。

### 用例二：日记管理

- 新增一篇日记。
- 在日记列表中查看。
- 进入详情页查看完整内容。
- 修改日记标题和正文。
- 删除日记后列表不再显示。

### 用例三：幸福瞬间互动

- 发布一条幸福瞬间。
- 在列表中查看。
- 点赞后点赞数增加。
- 再次点击取消点赞。
- 收藏后可在我的收藏中查看。

### 用例四：树洞匿名与评论

- 匿名发布一条树洞内容。
- 列表中显示匿名用户。
- 进入详情页发表评论。
- 评论保存后再次进入仍可查看。

### 用例五：搜索

- 创建包含指定关键词的日记、瞬间或树洞。
- 在搜索页输入关键词。
- 搜索结果按类型展示。
- 点击结果进入详情页。

### 用例六：数据持久化

- 注册用户并创建多条记录。
- 关闭应用。
- 重新打开应用并登录。
- 原有记录仍可正常查看。

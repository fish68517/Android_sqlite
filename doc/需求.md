设计一个旅游项目的手机APP小作业，需满足以下要求：

1. 页面设计‌：
   APP不能少于6个页面，包括但不限于首页、景点详情页、预订页、行程管理页、个人动态和个人中心页。
   具体页面设计如下：
    - 首页：展示旅游推荐、热门景点等信息。
    - 景点详情页：提供景点的详细介绍、图片
    - 预订页：允许用户选择日期、旅游产品进行旅游产品预订。
    - 行程管理页：显示用户的行程信息，包括景点、时间、路线等。
    - 个人动态：显示用户的最新动态：旅游动态页需支持用户上传图片和文字，展示个人旅游经历。其中图片需要支持Android的图片选择器功能，
      用户可以从手机相册中选择图片上传。需要视适配Android9.0 和 Android9.0及以上版本
    - 个人中心页：显示用户的个人信息。

2. 内容呈现‌：
   每个页面需图文并茂，提供丰富的视觉信息，增强用户体验。

3. 多媒体功能‌：
   加入背景音乐，并设置进度条指示播放进度，营造沉浸式的旅游氛围。音乐资源存放在 Androidstudio 的res/raw目录下，
   并确保APP在运行时能正确加载和播放。

4. 数据交互‌：
   APP需能访问本地数据库Splitet通过 SQLiteOpenHelper访问，正确读取数据。远程数据库指非APP自身的数据库，用于获取实时、全面的旅游信息。

5. 数据管理‌：
   对某一数据（如行程、预订信息等）具有添加、删除、查询、修改的功能，确保用户能灵活管理自己的旅游计划。
6. 需要使用最简单的技术 和 ui 控件， 如TextView、ImageView、Button等，避免使用复杂的自定义控件。

# 基于 Android 的日记系统功能清单

## 1. 范围说明

本系统依据《P92784基于Android的日记系统设计与实现-开题.docx》中的研究内容进行裁剪和落地实现，目标是完成一个可在 Android 手机或模拟器上运行的本地日记系统。

开发约束如下：

- 不实现管理员功能，不开发后台管理端。
- 使用 Android Studio + Java 开发。
- 数据库存储使用 Android 本地 SQLite。
- 不使用 Room，数据库访问直接基于 `SQLiteOpenHelper` 封装。
- Gradle 使用项目根目录 `downloads` 目录下的本地 Gradle 8.2 资源。
- 系统以本地单机应用为主，不依赖服务器、远程数据库或云同步。

本次毕业设计建议将原开题报告中的“管理员管理、ECharts 后台统计、云端同步、后台公告发布”等内容删除或降级为本地展示功能，重点保证用户端核心业务完整、可运行、可演示。

## 2. 功能优先级

### 2.1 必须实现功能

#### 2.1.1 用户账户模块

- 用户注册：输入用户名、密码、确认密码、邮箱完成注册。
- 用户登录：输入用户名和密码进入系统。
- 登录状态维护：使用 `SharedPreferences` 保存当前登录用户 ID 和基础信息。
- 退出登录：清除本地登录状态并返回登录页面。
- 修改密码：登录后输入旧密码、新密码完成密码修改。
- 个人资料维护：修改昵称、邮箱、头像路径或个性签名。

#### 2.1.2 心情日记模块

- 新建日记：填写标题、正文、心情、天气、标签等信息。
- 编辑日记：修改已保存的日记内容。
- 删除日记：删除本人创建的日记记录。
- 日记列表：按创建时间或更新时间倒序展示。
- 日记详情：查看完整标题、正文、心情、标签、创建时间、更新时间。
- 草稿保存：未完成内容可先保存为草稿。
- 日记状态：支持草稿、已发布或私密状态，便于论文中体现内容管理设计。
- 本地图片路径记录：允许选择图片后保存本地路径，作为日记附件展示。

#### 2.1.3 幸福瞬间模块

- 发布幸福瞬间：记录一段简短文字，可附加图片路径。
- 幸福瞬间列表：展示本人或本地用户发布的幸福瞬间。
- 幸福瞬间详情：查看内容、图片、发布时间、点赞数、收藏状态。
- 点赞：对幸福瞬间进行本地点赞或取消点赞。
- 收藏：对幸福瞬间进行本地收藏或取消收藏。
- 删除本人内容：当前登录用户只能删除自己发布的幸福瞬间。

#### 2.1.4 树洞模块

- 发布树洞内容：填写心声、秘密、烦恼或想法。
- 匿名发布：记录匿名标记，列表中隐藏真实昵称。
- 树洞列表：按时间展示树洞内容。
- 树洞详情：查看内容和评论。
- 评论树洞：对树洞内容发表评论。
- 删除本人树洞：当前登录用户只能删除自己发布的树洞。

#### 2.1.5 搜索与筛选模块

- 关键词搜索：根据标题、正文、标签搜索日记、幸福瞬间、树洞内容。
- 类型筛选：按日记、幸福瞬间、树洞分类查看搜索结果。
- 时间筛选：按日期范围或月份查看记录。
- 标签筛选：根据标签查看相关日记。
- 心情筛选：根据开心、平静、难过、焦虑等心情分类查看日记。

#### 2.1.6 个人中心模块

- 查看个人资料：展示头像、昵称、邮箱、注册时间。
- 我的日记：查看当前用户创建的日记。
- 我的幸福瞬间：查看当前用户发布的幸福瞬间。
- 我的树洞：查看当前用户发布的树洞内容。
- 我的收藏：查看收藏过的日记或幸福瞬间。
- 我的点赞：查看点赞过的幸福瞬间。
- 数据统计：展示本地记录数量，例如日记总数、幸福瞬间数量、树洞数量、收藏数量。

#### 2.1.7 数据安全与本地设置

- 密码存储：不明文保存密码，至少使用 SHA-256 或同等级摘要处理。
- 数据隔离：不同用户只能编辑和删除自己的内容。
- 数据库初始化：使用 `SQLiteOpenHelper` 创建和升级表结构。
- 表单校验：用户名、密码、邮箱、标题、正文等输入必须校验。
- 异常提示：数据库操作失败、输入为空、密码错误等情况给出明确提示。

### 2.2 建议实现功能

#### 2.2.1 交流论坛模块

- 发布帖子：用户发布交流内容。
- 帖子列表：按发布时间展示帖子。
- 帖子详情：查看帖子正文与评论。
- 评论帖子：用户对帖子发表评论。
- 删除本人帖子：当前用户只能删除自己发布的帖子。

说明：论坛功能在无服务器环境下只能作为本地多用户数据演示，不涉及真实联网交流。

#### 2.2.2 留言反馈模块

- 提交反馈：用户填写意见、建议或问题。
- 我的反馈：查看自己提交的反馈记录。
- 反馈状态：默认保存为“待处理”，不实现管理员回复。

说明：由于不做管理员功能，反馈模块只作为用户端意见记录功能，不实现后台处理流程。

#### 2.2.3 公告信息模块

- 查看公告：展示应用内置公告或使用说明。
- 公告详情：查看公告标题、内容、发布时间。

说明：由于不做管理员功能，公告内容可在本地数据库初始化时预置，不提供后台发布、修改、删除。

### 2.3 可选增强功能

- 日历视图：按日期展示当天是否有日记。
- 心情统计：按心情类型统计数量，用普通 Android 图形或列表展示，不使用 ECharts。
- 标签管理：新增、修改、删除常用标签。
- 图片附件管理：支持多个图片路径与日记关联。
- 本地备份：将 SQLite 数据导出为本地文件。
- 本地恢复：从备份文件恢复数据库。
- 应用锁：进入应用时要求输入二级密码。

## 3. 明确不实现的功能

- 用户管理、内容审核、删除他人不良内容。
- 后台公告发布、修改、删除。
- 后台统计图表。
- ECharts 可视化。
- Web 后台、服务器接口、云同步。

## 5. SQLite 数据表建议

### 5.1 用户表 `users`

- `id`：用户 ID，主键自增。
- `username`：用户名，唯一。
- `password_hash`：密码摘要。
- `email`：邮箱。
- `nickname`：昵称。
- `avatar_path`：头像本地路径。
- `signature`：个性签名。
- `created_at`：注册时间。
- `updated_at`：更新时间。

### 5.2 日记表 `diaries`

- `id`：日记 ID，主键自增。
- `user_id`：所属用户 ID。
- `title`：标题。
- `content`：正文。
- `mood`：心情。
- `weather`：天气。
- `tags`：标签，使用逗号分隔或单独建标签表。
- `image_path`：图片路径。
- `status`：状态，草稿、已发布、私密。
- `created_at`：创建时间。
- `updated_at`：更新时间。

### 5.3 幸福瞬间表 `moments`

- `id`：瞬间 ID，主键自增。
- `user_id`：发布用户 ID。
- `content`：内容。
- `image_path`：图片路径。
- `created_at`：创建时间。
- `updated_at`：更新时间。

### 5.4 树洞表 `tree_holes`

- `id`：树洞 ID，主键自增。
- `user_id`：发布用户 ID。
- `content`：内容。
- `is_anonymous`：是否匿名。
- `created_at`：创建时间。
- `updated_at`：更新时间。

### 5.5 评论表 `comments`

- `id`：评论 ID，主键自增。
- `user_id`：评论用户 ID。
- `target_type`：评论对象类型，例如 tree_hole、post。
- `target_id`：评论对象 ID。
- `content`：评论内容。
- `created_at`：创建时间。

### 5.6 点赞表 `likes`

- `id`：点赞 ID，主键自增。
- `user_id`：点赞用户 ID。
- `target_type`：点赞对象类型，例如 moment。
- `target_id`：点赞对象 ID。
- `created_at`：创建时间。

### 5.7 收藏表 `favorites`

- `id`：收藏 ID，主键自增。
- `user_id`：收藏用户 ID。
- `target_type`：收藏对象类型，例如 diary、moment。
- `target_id`：收藏对象 ID。
- `created_at`：创建时间。

### 5.8 帖子表 `posts`

- `id`：帖子 ID，主键自增。
- `user_id`：发布用户 ID。
- `title`：标题。
- `content`：正文。
- `created_at`：创建时间。
- `updated_at`：更新时间。

### 5.9 反馈表 `feedback`

- `id`：反馈 ID，主键自增。
- `user_id`：提交用户 ID。
- `content`：反馈内容。
- `status`：状态，默认待处理。
- `created_at`：创建时间。

### 5.10 公告表 `notices`

- `id`：公告 ID，主键自增。
- `title`：公告标题。
- `content`：公告内容。
- `created_at`：发布时间。

## 6. 毕设验收重点

- 应用可以正常安装、启动、注册、登录、退出。
- 日记可以完整完成新增、查询、修改、删除。
- SQLite 数据可以持久化保存，重启应用后数据仍存在。
- `SQLiteOpenHelper` 的表结构、增删改查代码清晰可说明。
- 至少包含日记、幸福瞬间、树洞、搜索、个人中心五个核心模块。
- 不出现管理员入口或后台管理功能。
- 论文中技术路线与实际项目一致，即 Android Studio、Java、SQLite、`SQLiteOpenHelper`、本地 Gradle 8.2。

# 个人笔记应用开发文档

## 1. 项目概述

本项目旨在开发一款个人笔记应用，用户可以通过该应用进行登录注册，随时随地记录和管理自己的笔记。应用支持文本和图片形式的笔记内容，并提供分类、搜索、分享等功能，以帮助用户高效地组织和查阅信息。

## 2. 功能设计

根据需求分析，应用包含以下核心功能：

- **用户模块**:
  - 用户注册：提供新用户注册功能。
  - 用户登录：已注册用户可以登录系统。
- **笔记管理**:
  - 创建笔记：支持创建包含标题、文本内容和图片的笔记。
  - 编辑笔记：用户可以修改已有笔记的全部内容。
  - 查看笔记：按列表形式展示所有笔记，点击可查看详情。
  - 删除笔记：用户可以删除笔记，已删除笔记将移入回收站。
- **分类管理**:
  - 创建分类：用户可以自定义新的笔记分类。
  - 查看分类：以列表形式展示所有分类。
  - 按分类筛选：在主页可以根据分类筛选笔记列表。
- **搜索功能**:
  - 提供关键词搜索功能，可根据笔记的标题或内容进行模糊搜索。
- **分享功能**:
  - 提供一个虚拟的分享入口，点击后提示"分享成功"，不接入实际的第三方分享SDK。
- **回收站**:
  - 查看已删除笔记：提供回收站页面，展示所有被删除的笔记。
  - 恢复笔记：用户可以从回收站中将笔记恢复到原来的列表中。
  - 彻底删除：用户可以从回收站中永久删除笔记。
- **图片处理**:
  - 用户可在编辑笔记时从手机相册选择图片并插入到笔记中。
  - 图片将作为二进制数据(BLOB)存储在SQLite数据库中。

## 3. 页面设计

应用主要包含以下几个页面：

1.  **登录/注册页 (LoginActivity)**
    - 提供用户名和密码输入框。
    - 包含"登录"和"注册"按钮。

2.  **主页面 (MainActivity)**
    - 采用 `BottomNavigationView` 作为底部导航，包含三个标签页：`笔记`、`分类`、`我的`。
    - 使用 `Fragment` 进行页面切换。
    - **笔记 Fragment**:
      - 默认展示所有笔记的列表 (`RecyclerView`)。
      - 提供一个下拉菜单，用于按分类筛选笔记。
      - 右下角提供一个悬浮按钮 (`FloatingActionButton`) 用于创建新笔记。
      - 列表项应显示笔记标题和部分内容预览。
    - **分类 Fragment**:
      - 展示所有分类的列表。
      - 提供添加新分类的入口。
    - **我的 Fragment**:
      - 显示当前登录的用户名。
      - 提供"回收站"入口。
      - 提供"退出登录"按钮。

3.  **笔记编辑/详情页 (NoteEditorActivity)**
    - 用于创建和编辑笔记。
    - 包含标题 (`EditText`)、内容 (`EditText`) 的输入区域。
    - 包含一个 `ImageView` 用于显示/预览笔记图片。
    - 提供"从相册选择图片"按钮。
    - 提供"保存"按钮。

4.  **搜索页 (SearchActivity)**
    - 包含一个搜索框 (`SearchView`)。
    - 实时根据输入内容展示搜索结果列表。

5.  **回收站页 (RecycleBinActivity)**
    - 展示所有已删除笔记的列表。
    - 列表项提供"恢复"和"彻底删除"的操作按钮。

## 4. 架构设计

本项目采用 **MVP (Model-View-Presenter)** 架构模式，以实现逻辑与视图的分离，提高代码的可维护性和可测试性。

- **Model (模型层)**:
  - 负责数据的获取和存储，与数据库进行交互。
  - 包含 `UserDao`, `NoteDao`, `CategoryDao` 等数据访问对象。
  - 负责处理所有的数据库操作（增、删、改、查）。
  - 不与任何上层(View/Presenter)直接交互，只提供数据接口。

- **View (视图层)**:
  - 由 `Activity`、`Fragment` 和对应的 XML 布局文件组成。
  - 负责UI的绘制和展示，响应用户的交互操作（如点击、输入）。
  - 自身不处理任何业务逻辑，当用户产生操作时，将事件传递给 Presenter。
  - 从 Presenter 接收数据并更新UI。
  - 例如 `MainActivity` (实现 `INoteView` 接口)， `NoteEditorActivity` (实现 `INoteEditorView` 接口)。

- **Presenter (表示层)**:
  - 作为 View 和 Model 之间的桥梁。
  - 从 View接收事件，并根据事件调用 Model 层进行数据操作。
  - 从 Model 层获取数据后，调用 View 层的接口将数据更新到UI上。
  - 负责处理应用的业务逻辑。
  - 例如 `NotePresenter` (处理笔记列表的逻辑), `NoteEditorPresenter` (处理笔记编辑的逻辑)。

### 交互流程示例 (加载笔记列表):
1.  `MainActivity` (View) 启动，调用 `NotePresenter` 的 `loadNotes()` 方法。
2.  `NotePresenter` 调用 `NoteDao` (Model) 的 `queryAllNotes()` 方法从数据库获取数据。
3.  `NoteDao` 执行SQL查询，并将笔记列表数据返回给 `NotePresenter`。
4.  `NotePresenter` 收到数据后，调用 `MainActivity` (View) 的 `showNotes(noteList)` 方法。
5.  `MainActivity` (View) 更新 `RecyclerView`，将笔记列表展示在界面上。

## 5. 数据库设计

数据库采用 SQLite。详细的表结构和字段定义请参见项目中的 `doc/db.sql` 文件。

- **`users`**: 存储用户信息。
- **`categories`**: 存储用户创建的分类信息。
- **`notes`**: 存储笔记的核心内容，包括标题、正文和图片。
- **`deleted_notes`**: 作为回收站，存储被用户删除的笔记信息。

## 6. 技术栈与第三方库

- **开发语言**: Java / Kotlin
- **数据库**: SQLite
- **架构模式**: MVP
- **图片加载**: `Glide` - 高效加载和显示图片，尤其是从数据库或本地文件加载。
- **视图组件**: `RecyclerView` (用于列表), `BottomNavigationView` (底部导航), `CardView` (美化列表项), `FloatingActionButton` (悬浮按钮)。

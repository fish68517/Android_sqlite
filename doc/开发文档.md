# 个人图书档案管理系统 - 功能开发文档

## 1. 简介

本项目是一个基于 Android 平台的个人图书档案管理系统。用户可以管理自己的图书收藏，对图书进行分类、添加、编辑、删除和查看操作。应用首页提供了核心数据的统计仪表盘，方便用户快速了解图书和分类的总体情况。

---

## 2. 核心功能模块

应用主要由一个主界面和四个核心功能模块构成，通过底部导航栏进行切换。

### 2.1. 主界面与导航

- **实现类**: `AdminMainActivity.java`
- **布局**: `activity_main_admin.xml`

应用的主界面包含一个 `BottomNavigationView`，提供了四个导航选项：

- **首页**: 跳转至 `HomeFragment`。
- **图书**: 跳转至 `BookFragment`。
- **分类**: 跳转至 `CategoryFragment`。
- **我的**: 跳转至 `ProfileFragment`。

一个 `FrameLayout` 作为容器，用于动态替换和展示选中的 `Fragment`。

### 2.2. 首页 (HomeFragment)

- **实现类**: `HomeFragment.java`
- **布局**: `fragment_home.xml`

作为应用的仪表盘，首页以卡片 (`CardView`) 的形式直观地展示了关键的统计数据。

- **功能**:
  - **图书总数**: 显示数据库中所有图书的总数量。
  - **分类总数**: 显示所有已创建的图书分类的总数量。
- **数据来源**:
  - 数据在 `onResume` 生命周期方法中加载，确保每次回到首页都能刷新。
  - 通过调用 `OpenHelperDataBase` 中的 `getTotalBookCount()` 和 `getTotalCategoryCount()` 方法从数据库获取数据。

### 2.3. 图书管理 (BookFragment)

- **实现类**: `BookFragment.java`
- **相关 Activity**: `AddEditBookActivity.java`, `BookDetailActivity.java`

此模块是应用的核心，负责图书的增删改查。

- **功能**:
  - 使用 `RecyclerView` 列表展示所有图书。
  - 通过 `FloatingActionButton` 跳转到 `AddEditBookActivity` 添加新书。
  - 列表项提供"查看"、"编辑"、"删除"操作。

### 2.4. 分类管理 (CategoryFragment)

- **实现类**: `CategoryFragment.java`
- **相关 Activity**: `CategoryEditActivity.java`
- **适配器**: `CategoryAdapter.java`
- **列表项布局**: `item_category.xml`

此模块是本次开发的主要内容，提供了对图书分类的完整管理功能。

- **功能**:
  - **列表展示**: 使用 `RecyclerView` 和 `CategoryAdapter` 显示所有分类。
  - **添加分类**: 点击右下角的 `FloatingActionButton` 会启动 `CategoryEditActivity` 进入添加模式。
  - **编辑分类**: 点击列表项中的"编辑"按钮，会启动 `CategoryEditActivity` 并传入当前分类的ID，进入编辑模式。
  - **删除分类**: 点击列表项中的"删除"按钮，会弹出一个 `AlertDialog` 对话框，请求用户确认。确认后将从数据库中删除该分类。
- **数据交互**:
  - `CategoryFragment` 与 `CategoryEditActivity` 之间通过 `ActivityResultLauncher` 进行通信。当 `CategoryEditActivity` 完成操作（添加或编辑）后，会返回一个 `RESULT_OK` 信号，`CategoryFragment` 接收到后会自动刷新列表。
  - 所有数据库操作均通过 `OpenHelperDataBase` 中对应的方法完成，如 `getAllCategories()`, `deleteCategory()` 等。

### 2.5. 个人中心 (ProfileFragment)

- **实现类**: `ProfileFragment.java`

提供用户信息展示、编辑和退出登录的功能。

---

## 3. 数据库设计

数据持久化使用 Android 内置的 SQLite 数据库。

- **实现类**: `OpenHelperDataBase.java`
- **主要数据表**:
  - `admin`: 存储管理员用户信息。
  - `category`: 存储图书分类信息（ID, 名称）。
  - `book`: 存储图书详细信息，并有一个外键 `category_id` 关联到 `category` 表。
  - `users`: (如果适用)存储普通用户信息。

---

## 4. 项目代码结构

项目遵循标准的 Android 开发模式，关键代码按功能分包存储：

- `com.archive.app.activity`: 存放所有的 `Activity` 类。
- `com.archive.app.fragment`: 存放所有的 `Fragment` 类。
- `com.archive.app.adapter`: 存放用于 `RecyclerView` 的适配器，如 `CategoryAdapter`。
- `com.archive.app.model`: 存放数据模型类（POJO），如 `Book.java`, `Category.java`。
- `com.archive.app.db`: 存放数据库帮助类 `OpenHelperDataBase.java`，封装所有数据库操作。

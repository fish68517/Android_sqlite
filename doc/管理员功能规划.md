# 管理员功能规划

## 1. 开发目标

在现有 Android 本地日记系统基础上增加管理员功能。管理员端仍采用 Android Studio + Java 开发，数据库仍使用 Android 本地 SQLite，并继续通过 `SQLiteOpenHelper` 直接完成数据库创建、升级和增删改查操作，不使用 Room。

管理员端与普通用户端共用同一个 `MainActivity`。用户登录后，系统根据用户角色判断进入普通用户界面或管理员界面：

- 普通用户：继续使用 `MainActivity + 底部导航栏 + Fragment`。
- 管理员：使用 `MainActivity + 侧边导航栏 + Fragment`。

管理员页面中的菜单、标题、按钮、输入提示等固定界面文案统一放入 XML 布局或 `strings.xml` 资源文件，不在 Java 代码中直接硬编码显示。

## 2. 管理员账号设计

系统初始化时预置一个管理员账号，便于毕业设计演示和答辩测试。

| 项目 | 内容 |
|---|---|
| 用户名 | admin |
| 默认密码 | admin123456 |
| 用户角色 | admin |
| 用途 | 登录后进入管理员侧边导航界面 |

数据库 `users` 表增加 `role` 字段，用于区分普通用户和管理员用户。

## 3. 管理员端页面架构

管理员端采用侧边导航栏结构，主页面由 `MainActivity` 承载，不额外创建新的管理端 Activity。

侧边导航菜单规划如下：

| 菜单名称 | Fragment | 功能说明 |
|---|---|---|
| 数据统计 | AdminDashboardFragment | 内容数量、互动数量、趋势图表展示 |
| 用户管理 | AdminManageFragment(users) | 用户新增、修改、删除、查询 |
| 日记管理 | AdminManageFragment(diaries) | 心情日记查看、修改、删除、查询 |
| 瞬间管理 | AdminManageFragment(moments) | 幸福瞬间查看、修改、删除、查询 |
| 树洞管理 | AdminManageFragment(tree_holes) | 树洞查看、修改、删除、查询 |
| 交流论坛管理 | AdminManageFragment(posts) | 帖子新增、修改、删除、查询、查看评论 |
| 留言反馈管理 | AdminManageFragment(feedback) | 反馈查看、删除、回复 |
| 公告信息管理 | AdminManageFragment(notices) | 公告发布、修改、删除、查询 |
| 退出登录 | MainActivity.logout() | 清除登录状态，返回登录页面 |

## 4. 管理员功能清单

### 4.1 用户管理

管理员可以完成以下操作：

- 查询用户列表。
- 根据关键词搜索用户名、昵称、邮箱。
- 添加新用户。
- 修改用户昵称、邮箱、签名、角色。
- 删除已存在用户。

限制说明：

- 默认管理员账号不建议删除。
- 密码以 SHA-256 摘要形式保存。

### 4.2 日记管理

管理员可以完成以下操作：

- 查看系统中所有用户发布的心情日记。
- 根据标题、正文、标签进行搜索。
- 修改日记标题、正文、心情、天气、标签和状态。
- 删除不合适的日记内容。

### 4.3 瞬间管理

管理员可以完成以下操作：

- 查看系统中所有幸福瞬间。
- 根据内容关键词搜索幸福瞬间。
- 修改瞬间文字内容。
- 删除不合适的幸福瞬间。
- 查看瞬间点赞数和收藏数。

### 4.4 树洞管理

管理员可以完成以下操作：

- 查看系统中所有树洞内容。
- 根据内容关键词搜索树洞。
- 修改树洞内容。
- 删除不合适的树洞内容。
- 查看树洞评论数量。

### 4.5 交流论坛管理

为满足开题报告中的论坛管理要求，数据库新增 `posts` 帖子表。管理员可以完成以下操作：

- 查看帖子列表。
- 发布帖子。
- 修改帖子标题和正文。
- 删除不良帖子。
- 查看帖子评论。

评论仍复用 `comments` 表，帖子评论的 `target_type` 为 `post`。

### 4.6 留言反馈管理

管理员可以完成以下操作：

- 查看用户提交的留言反馈。
- 根据反馈内容搜索。
- 回复反馈信息。
- 修改反馈状态。
- 删除反馈记录。

数据库 `feedback` 表增加 `reply` 字段保存管理员回复。

### 4.7 公告信息管理

管理员可以完成以下操作：

- 发布公告。
- 修改公告标题和内容。
- 删除公告。
- 查询公告。

公告用于在系统中保存本地公告数据，不依赖服务器。

## 5. 统计图表规划

管理员端需要比普通用户端更完整的统计图表，规划放在“数据统计”页面。

### 5.1 内容统计图

展示系统内容数量，包括：

- 用户数量。
- 日记数量。
- 幸福瞬间数量。
- 树洞数量。
- 帖子数量。
- 反馈数量。
- 公告数量。

采用柱状图展示，便于直观看出各模块数据规模。

### 5.2 内容趋势折线图

统计最近 7 天系统新增内容趋势，包括：

- 日记新增数量。
- 瞬间新增数量。
- 树洞新增数量。
- 帖子新增数量。

采用折线图展示，用于体现系统内容活跃度变化。

### 5.3 互动统计曲线图

统计系统互动数据，包括：

- 幸福瞬间点赞数量。
- 幸福瞬间收藏数量。
- 日记点赞数量。
- 日记收藏数量。
- 树洞评论数量。
- 帖子评论数量。

采用曲线图或折线图展示，用于体现系统互动活跃情况。

## 6. 数据库调整规划

| 数据表 | 调整内容 | 说明 |
|---|---|---|
| users | 增加 `role` 字段 | 区分普通用户和管理员 |
| feedback | 增加 `reply` 字段 | 保存管理员回复内容 |
| posts | 新增帖子表 | 支持交流论坛管理 |
| comments | 复用现有表 | 通过 `target_type=post` 保存帖子评论 |

## 7. 实施顺序

1. 更新数据库版本，增加管理员账号、角色字段、帖子表、反馈回复字段。
2. 改造登录逻辑，登录后保存用户角色。
3. 改造 `MainActivity`，根据角色切换普通用户底部导航或管理员侧边导航。
4. 新增管理员侧边导航布局、菜单和字符串资源。
5. 新增管理员统计图表页面。
6. 新增管理员通用管理页面，实现用户、日记、瞬间、树洞、帖子、反馈、公告的查询、增加、修改、删除。
7. 使用本地 Gradle 8.2 编译验证。

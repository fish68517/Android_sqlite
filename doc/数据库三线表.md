# 数据库三线表

本文档用于辅助论文“数据库设计”章节撰写。系统数据库采用 Android 本地 SQLite，数据库创建与升级由 `SQLiteOpenHelper` 实现，数据库名称为 `personal_diary.db`。字段类型采用 SQLite 常用类型，包括 `INTEGER`、`TEXT`、`BLOB` 等。

## 表 1 用户信息表 users

| 字段名 | 数据类型 | 约束 | 字段说明 |
|---|---:|---|---|
| id | INTEGER | PRIMARY KEY AUTOINCREMENT | 用户编号 |
| username | TEXT | UNIQUE NOT NULL | 用户名 |
| password_hash | TEXT | NOT NULL | 密码摘要值 |
| email | TEXT |  | 邮箱 |
| nickname | TEXT |  | 昵称 |
| signature | TEXT |  | 个性签名 |
| created_at | TEXT |  | 注册时间 |
| updated_at | TEXT |  | 更新时间 |

说明：`users` 表用于保存系统用户基础信息。系统不直接保存明文密码，而是保存密码经过 SHA-256 处理后的摘要值。

## 表 2 心情日记表 diaries

| 字段名 | 数据类型 | 约束 | 字段说明 |
|---|---:|---|---|
| id | INTEGER | PRIMARY KEY AUTOINCREMENT | 日记编号 |
| user_id | INTEGER | NOT NULL | 所属用户编号 |
| title | TEXT | NOT NULL | 日记标题 |
| content | TEXT | NOT NULL | 日记正文 |
| mood | TEXT |  | 心情 |
| weather | TEXT |  | 天气 |
| tags | TEXT |  | 标签 |
| status | TEXT |  | 日记状态 |
| created_at | TEXT |  | 创建时间 |
| updated_at | TEXT |  | 更新时间 |

说明：`diaries` 表是系统核心业务表，用于保存用户撰写的心情日记。系统通过 `user_id` 区分不同用户的数据。

## 表 3 幸福瞬间表 moments

| 字段名 | 数据类型 | 约束 | 字段说明 |
|---|---:|---|---|
| id | INTEGER | PRIMARY KEY AUTOINCREMENT | 瞬间编号 |
| user_id | INTEGER | NOT NULL | 发布用户编号 |
| content | TEXT | NOT NULL | 瞬间内容 |
| image_path | TEXT |  | 图片路径，兼容旧版本 |
| image_data | BLOB |  | 图片二进制数据 |
| created_at | TEXT |  | 创建时间 |
| updated_at | TEXT |  | 更新时间 |

说明：`moments` 表用于保存用户发布的幸福瞬间。图片从 Android 手机相册中选择后，经压缩转换为二进制数据并保存到 `image_data` 字段中，显示时从数据库读取并还原为图片。

## 表 4 树洞信息表 tree_holes

| 字段名 | 数据类型 | 约束 | 字段说明 |
|---|---:|---|---|
| id | INTEGER | PRIMARY KEY AUTOINCREMENT | 树洞编号 |
| user_id | INTEGER | NOT NULL | 发布用户编号 |
| content | TEXT | NOT NULL | 树洞内容 |
| is_anonymous | INTEGER | DEFAULT 0 | 是否匿名 |
| created_at | TEXT |  | 创建时间 |
| updated_at | TEXT |  | 更新时间 |

说明：`tree_holes` 表用于保存用户发布的树洞内容。`is_anonymous` 字段用于控制页面显示真实昵称或匿名用户。

## 表 5 评论信息表 comments

| 字段名 | 数据类型 | 约束 | 字段说明 |
|---|---:|---|---|
| id | INTEGER | PRIMARY KEY AUTOINCREMENT | 评论编号 |
| user_id | INTEGER | NOT NULL | 评论用户编号 |
| target_type | TEXT | NOT NULL | 评论对象类型 |
| target_id | INTEGER | NOT NULL | 评论对象编号 |
| content | TEXT | NOT NULL | 评论内容 |
| created_at | TEXT |  | 评论时间 |

说明：`comments` 表用于保存评论数据。当前系统主要用于树洞评论，`target_type` 为 `tree_hole`。

## 表 6 点赞信息表 likes

| 字段名 | 数据类型 | 约束 | 字段说明 |
|---|---:|---|---|
| id | INTEGER | PRIMARY KEY AUTOINCREMENT | 点赞编号 |
| user_id | INTEGER | NOT NULL | 点赞用户编号 |
| target_type | TEXT | NOT NULL | 点赞对象类型 |
| target_id | INTEGER | NOT NULL | 点赞对象编号 |
| created_at | TEXT |  | 点赞时间 |

说明：`likes` 表用于记录用户点赞行为。系统设置 `UNIQUE(user_id, target_type, target_id)` 约束，防止同一用户对同一内容重复点赞。

## 表 7 收藏信息表 favorites

| 字段名 | 数据类型 | 约束 | 字段说明 |
|---|---:|---|---|
| id | INTEGER | PRIMARY KEY AUTOINCREMENT | 收藏编号 |
| user_id | INTEGER | NOT NULL | 收藏用户编号 |
| target_type | TEXT | NOT NULL | 收藏对象类型 |
| target_id | INTEGER | NOT NULL | 收藏对象编号 |
| created_at | TEXT |  | 收藏时间 |

说明：`favorites` 表用于记录用户收藏行为。系统设置 `UNIQUE(user_id, target_type, target_id)` 约束，防止重复收藏。

## 表 8 公告信息表 notices

| 字段名 | 数据类型 | 约束 | 字段说明 |
|---|---:|---|---|
| id | INTEGER | PRIMARY KEY AUTOINCREMENT | 公告编号 |
| title | TEXT |  | 公告标题 |
| content | TEXT |  | 公告内容 |
| created_at | TEXT |  | 发布时间 |

说明：`notices` 表用于保存本地预置公告信息。当前系统不提供管理员功能，因此公告内容由系统初始化时写入。

## 表 9 留言反馈表 feedback

| 字段名 | 数据类型 | 约束 | 字段说明 |
|---|---:|---|---|
| id | INTEGER | PRIMARY KEY AUTOINCREMENT | 反馈编号 |
| user_id | INTEGER | NOT NULL | 反馈用户编号 |
| content | TEXT | NOT NULL | 反馈内容 |
| status | TEXT |  | 反馈状态 |
| created_at | TEXT |  | 反馈时间 |

说明：`feedback` 表用于保存用户反馈信息。当前系统不实现管理员回复功能，反馈状态默认保存为“待处理”。

## 数据库表关系说明

| 关系项 | 关系说明 |
|---|---|
| 用户与日记 | 一个用户可以创建多篇日记，`diaries.user_id` 对应 `users.id` |
| 用户与幸福瞬间 | 一个用户可以发布多条幸福瞬间，`moments.user_id` 对应 `users.id` |
| 用户与树洞 | 一个用户可以发布多条树洞内容，`tree_holes.user_id` 对应 `users.id` |
| 树洞与评论 | 一条树洞可以拥有多条评论，`comments.target_id` 对应树洞编号 |
| 用户与点赞 | 一个用户可以点赞多个内容，点赞记录保存在 `likes` 表 |
| 用户与收藏 | 一个用户可以收藏多个内容，收藏记录保存在 `favorites` 表 |

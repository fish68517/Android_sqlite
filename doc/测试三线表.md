# 测试三线表

本文档用于辅助论文“系统测试”章节撰写。测试对象为基于 Android 的本地日记系统，主要测试系统的登录注册、日记管理、幸福瞬间、树洞、搜索、个人中心、图表统计和 SQLite 数据持久化等功能。

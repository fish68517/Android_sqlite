# 学生管理系统 App 技术文档

## 1. 基本功能

-   **应用布局文件 (`layout`)**:
    -   `activity_login.xml`: 用户登录界面，采用深绿与白色彩的现代化设计。
    -   `activity_main.xml`: 应用主界面，包含底部导航栏和用于承载 Fragment 的容器。
    -   `activity_add_student.xml`: 添加新学生的表单界面。
    -   `activity_student_detail.xml`: 展示单个学生详细信息的界面。
    -   `activity_add_class.xml`: 添加新班级的表单界面。
    -   `activity_edit_class.xml`: 编辑班级信息的界面。
    -   `fragment_student_list.xml`: 学生列表 Fragment 的布局，包含搜索框、列表和添加按钮。
    -   `fragment_class_list.xml`: 班级列表 Fragment 的布局，同样包含搜索、列表和添加按钮。
    -   `item_student.xml`: 学生列表 `RecyclerView` 的单项布局。
    -   `item_class_expandable.xml`: 可展开的班级列表 `RecyclerView` 的单项布局。

-   **基本按钮功能**:
    -   **登录/注册**: 在登录页面进行用户身份验证和新用户注册。
    -   **查看/详情**: 在学生/班级列表中点击条目，可查看详细信息或进入编辑页面。
    -   **添加**: 在学生或班级列表页面，通过浮动按钮进入相应的添加页面。
    -   **编辑**: 在班级列表页点击条目，可进入编辑页面修改班级信息。
    -   **删除**: 在学生和班级列表的每一项中，都有删除图标，点击后会弹出确认对话框，防止误操作。
    -   **搜索**: 在学生和班级列表页顶部提供搜索框，用于实时筛选数据。
    -   **展开/折叠**: 在班级列表中，点击箭头可展开或折叠该班级下的学生列表。
    -   **退出登录**: 在主界面的菜单中提供退出登录功能。

-   **数据库应用**:
    -   **是**: 本应用使用 SQLite 数据库进行数据持久化存储。
    -   通过 `StudentDBHelper.java` 类来管理数据库的创建、升级和增删改查操作。
    -   **初始数据**: 数据库在首次创建时会插入 **5** 条班级记录、**8** 条学生记录和 **18** 条学籍历史记录。

-   **图片资源**:
    -   **是**: 应用使用了图片资源，主要存放于 `res/drawable` 目录。
    -   包括用户头像 (`ic_avator`)、添加/删除/返回等功能的矢量图标 (`ic_add`, `ic_delete`, `ic_back` 等)。

## 2. 功能模块分析与 UI 设计

### 功能模块
1.  **用户认证模块**: 提供登录和注册功能，是访问应用其他功能的前提。
2.  **学生信息管理模块**: 核心模块，支持对学生信息的增、删、改、查。
3.  **班级信息管理模块**: 核心模块，支持对班级信息的增、删、改、查，并以可展开列表的形式关联学生。
4.  **数据检索模块**: 为学生和班级列表提供关键字搜索功能，方便用户快速定位数据。
5.  **数据统计模块**: (在此次开发中未详细实现，但已在底部导航栏预留入口) 用于未来扩展，如统计各班级人数、男女比例等。

### UI 设计
-   **登录页**: 采用了现代化的分层设计，顶部为深绿色背景，包含应用标题，营造出专业稳重的氛围。下半部分为圆角的白色卡片式表单，提供了清晰的输入区域和操作按钮，整体设计简洁且用户友好。
-   **主页**: 使用 `BottomNavigationView` 作为主导航，在"学生列表"、"班级列表"和"统计"三个核心功能间切换，符合现代移动应用的设计范式。
-   **列表页**: 学生和班级列表页均采用了 `RecyclerView` 来高效展示数据。列表项设计清晰，关键信息一目了然。每个列表页都配备了独立的搜索框和浮动添加按钮，使得数据检索和添加操作非常便捷。
-   **详情/编辑页**: 使用 `Toolbar` 提供清晰的页面标题和返回操作。表单部分采用 `Material Design` 的 `TextInputLayout` 和 `MaterialButton` 组件，不仅外观统一、美观，还提供了更好的用户交互体验（如输入提示、密码可见性切换等）。

## 3. 数据库设计

### 数据库结构
应用包含三个核心数据表：`classes` (班级表), `students` (学生表), 和 `student_status_history` (学籍状态历史表)。

-   **`classes` 表**
| 字段名 | 类型 | 约束 | 描述 |
| :--- | :--- | :--- | :--- |
| `class_id` | INTEGER | PRIMARY KEY, AUTOINCREMENT | 班级唯一标识 |
| `class_name` | VARCHAR(50) | NOT NULL | 班级名称 |
| `class_type` | VARCHAR(20) | NOT NULL | 班级类型 |
| `create_time` | TIMESTAMP | DEFAULT CURRENT_TIMESTAMP | 创建时间 |

-   **`students` 表**
| 字段名 | 类型 | 约束 | 描述 |
| :--- | :--- | :--- | :--- |
| `student_id` | INTEGER | PRIMARY KEY, AUTOINCREMENT | 学生唯一标识 |
| `name` | VARCHAR(50) | NOT NULL | 学生姓名 |
| `gender` | VARCHAR(10) | | 性别 |
| `class_id` | INTEGER | FOREIGN KEY | 所属班级ID |
| `admission_date`| DATE | | 入学日期 |
| `graduation_date`| DATE | | 毕业日期 |
| `status` | VARCHAR(20) | DEFAULT '在校' | 学籍状态 |
| `username` | VARCHAR(50) | | 登录用户名 |
| `password` | VARCHAR(50) | | 登录密码 |
| `is_admin` | INTEGER | DEFAULT 0 | 是否为管理员 |
| `create_time` | TIMESTAMP | DEFAULT CURRENT_TIMESTAMP | 创建时间 |

-   **`student_status_history` 表**
| 字段名 | 类型 | 约束 | 描述 |
| :--- | :--- | :--- | :--- |
| `id` | INTEGER | PRIMARY KEY, AUTOINCREMENT | 记录唯一标识 |
| `student_id` | INTEGER | FOREIGN KEY | 学生ID |
| `status` | VARCHAR(20) | NOT NULL | 变更后的状态 |
| `change_date` | DATE | NOT NULL | 变更日期 |
| `create_time` | TIMESTAMP | DEFAULT CURRENT_TIMESTAMP | 创建时间 |


### 数据库核心代码 (`StudentDBHelper.java`)
```java
@Override
public void onCreate(SQLiteDatabase db) {
    // 创建班级表
    db.execSQL("CREATE TABLE classes (" +
            "class_id INTEGER PRIMARY KEY AUTOINCREMENT," +
            "class_name VARCHAR(50) NOT NULL," +
            "class_type VARCHAR(20) NOT NULL," +
            "create_time TIMESTAMP DEFAULT CURRENT_TIMESTAMP" +
            ")");

    // 创建学生表
    db.execSQL("CREATE TABLE students (" +
            "student_id INTEGER PRIMARY KEY AUTOINCREMENT," +
            "name VARCHAR(50) NOT NULL," +
            "gender VARCHAR(10)," +
            "class_id INTEGER," +
            "admission_date DATE," +
            "graduation_date DATE," +
            "status VARCHAR(20) DEFAULT '在校'," +
            "username VARCHAR(50)," +
            "password VARCHAR(50)," +
            "is_admin INTEGER DEFAULT 0," +
            "create_time TIMESTAMP DEFAULT CURRENT_TIMESTAMP," +
            "FOREIGN KEY (class_id) REFERENCES classes(class_id)" +
            ")");

    // 创建学籍状态变更记录表
    db.execSQL("CREATE TABLE student_status_history (" +
            "id INTEGER PRIMARY KEY AUTOINCREMENT," +
            "student_id INTEGER," +
            "status VARCHAR(20) NOT NULL," +
            "change_date DATE NOT NULL," +
            "create_time TIMESTAMP DEFAULT CURRENT_TIMESTAMP," +
            "FOREIGN KEY (student_id) REFERENCES students(student_id)" +
            ")");
```

## 4. 功能结构分析
应用的功能结构清晰，以用户认证为起点，主功能界面为核心，各类操作页面为分支。

1.  **启动与认证**: 用户打开 App，首先进入 `LoginActivity`。UI 设计引导用户输入凭据登录。登录成功后，进入 `MainActivity`。
2.  **主界面与导航**: `MainActivity` 是应用的核心枢纽。界面底部有一个 `BottomNavigationView`，包含"学生列表"、"班级列表"和"统计"三个选项卡。默认显示 `StudentListFragment`。用户通过点击导航栏在不同的功能 Fragment 之间无缝切换。
3.  **学生管理流程**:
    -   在 `StudentListFragment` 中，用户可以滚动查看所有学生，或使用搜索框进行筛选。
    -   点击右上角的浮动添加按钮，会跳转到 `AddStudentActivity`，其界面是一个表单，用于录入新学生信息。
    -   点击列表中任一学生的删除图标，会弹出一个 `AlertDialog` 提示框，确认后即可删除该学生。
4.  **班级管理流程**:
    -   切换到 `ClassListFragment`，展示所有班级。
    -   点击班级条目右侧的箭头，会动态展开或折叠该班级下的学生子列表。
    -   点击班级条目本身，会跳转到 `EditClassActivity`，界面提供表单用于修改班级名称。
    -   点击删除图标，同样会弹出确认对话框，确认后会删除该班级及其下的所有学生，保证了数据的完整性。
    -   点击浮动添加按钮，会跳转到 `AddClassActivity` 以创建新班级。


## 5. 总结与体会
在本次学生管理 App 的设计与实现过程中，我全面运用了 Android 开发的核心知识，从 UI 布局设计到后台数据库交互，再到用户交互逻辑的实现，是一次非常宝贵的综合实践。

开发过程中，我遇到了一些典型问题。例如，在定义班级数据模型时，我最初将类命名为 `Class`，这与 Java 核心库的 `java.lang.Class` 发生了命名冲突，导致编译时出现歧义。为了解决这个问题，我采用了使用类的完全限定名 (`com.example.studentmanager.model.Class`) 的方式来精确指定我要使用的数据模型，避免了对大量代码进行重构的风险。此外，在实现删除班级功能时，我意识到必须先删除班级下的所有学生，否则会因为外键约束导致操作失败或产生孤立数据，这让我对数据库设计的完整性有了更深刻的理解。

目前，应用还存在一些可以改进的地方。比如，当前的数据操作是直接在主线程中执行的，对于更复杂或大量的数据操作，可能会导致界面卡顿。未来的改进方向是引入异步处理机制，例如使用 `AsyncTask` 或者更现代的协程 (Coroutines) 来执行数据库操作。此外，可以引入像 Room 这样的 ORM 框架来替代手写的 SQL 语句，这样不仅能减少样板代码，还能在编译期进行 SQL 语法检查，提高代码的健壮性。

通过本次课程设计，我不仅巩固了 `Activity`、`Fragment`、`RecyclerView`、`SQLite` 等 Android 基础组件的使用，还对如何构建一个结构清晰、功能完整的 App 有了更全面的认识。从需求分析到 UI 设计，再到编码实现和调试，整个过程锻炼了我的系统思维和问题解决能力。我计划在未来深入学习更先进的应用架构，如 MVVM，并结合 Jetpack 组件库，来构建更现代化、更易于维护的 Android 应用。

# 更新功能审核清单

## 1. 需求确认

- 是否确认新增播放模式：顺序播放、列表循环、单曲循环、随机播放。
- 是否确认播放模式需要本地保存。
- 是否确认自建歌单仅本地保存，不做云同步。
- 是否确认自建歌单首期需要支持创建、删除、添加歌曲、移除歌曲。
- 是否确认定时关闭首期使用固定时间选项。
- 是否确认定时关闭不保证应用进程被系统杀死后继续生效。

## 2. 播放模式审核点

- 播放页是否需要展示模式文字。
- 播放页是否需要展示模式图标。
- 点击下一首时，单曲循环模式是否仍允许切到下一首。
- 随机播放是否需要记录历史，避免短时间内重复播放。
- 顺序播放到最后一首后，是暂停在最后一首开头，还是停留在最后一首末尾。

## 3. 自建歌单审核点

- 是否允许创建同名歌单。
- 删除歌单时是否需要二次确认。
- 歌单是否需要支持重命名。
- 歌单内是否允许重复歌曲。
- 添加歌曲入口首期是否只放在歌单详情页。
- 是否需要从音乐库列表直接添加歌曲到歌单。

## 4. 定时关闭审核点

- 固定时间选项是否采用 15/30/45/60 分钟。
- 是否需要支持自定义分钟数。
- 是否需要“当前歌曲播放完后关闭”。
- 到时间后是暂停播放，还是完全清空播放状态。
- 设置定时关闭后是否需要在播放页持续显示剩余时间。

## 5. 页面审核点

- 播放页新增按钮后是否仍保持简洁。
- 歌单页是否保留“我喜欢”和“最近播放”。
- 自建歌单是否放在歌单页第三块区域。
- 歌单详情页是否使用独立 Activity。
- 空状态文案是否清楚。

## 6. 技术审核点

- 首期是否接受使用 `SharedPreferences + Gson` 保存自建歌单。
- 是否暂缓引入 Room 数据库。
- 是否继续使用 `MediaPlayer`。
- 是否继续保持 Java 开发。
- 是否继续保持简体中文资源文件直接写中文。

## 7. 建议审核结论

建议本次按以下结论执行：

- 播放模式：通过，优先实施。
- 定时关闭：通过，和播放模式一起接入 `MusicPlayerManager`。
- 自建歌单：通过，但分阶段实施，先完成基础创建和详情，再补添加歌曲与播放联动。
- 数据方案：首期使用 `SharedPreferences + Gson`，后续如数据复杂度提升再迁移到 Room。

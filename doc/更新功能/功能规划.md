# 更新功能规划

## 1. 更新目标

本次更新围绕老师提出的三个方向补齐播放器体验：

- 播放模式：支持顺序播放、列表循环、单曲循环、随机播放。
- 自建歌单：支持用户创建歌单、查看歌单、向歌单添加歌曲、从歌单移除歌曲、删除歌单。
- 定时关闭：支持用户设置倒计时，到点后自动暂停播放，并清除当前定时任务。

本次仍然保持当前项目约束：Android 原生 Java 开发、简体中文界面、本地运行、不依赖服务端。

## 2. 当前基础

当前系统已经具备以下基础能力：

- 本地音乐扫描与音乐库展示。
- `MediaPlayer` 基础播放控制。
- 当前播放队列。
- 播放页进度同步。
- 歌词显示。
- 最近播放记录。
- 歌曲收藏。
- `主页 + 底部导航栏 + Fragment` 主架构。

本次新增功能会复用现有的 `MusicPlayerManager`、`MusicLibraryRepository`、`UserMusicStateRepository`、`PlaylistFragment` 和 `PlayerActivity`，避免重新搭建架构。

## 3. 播放模式功能规划

### 3.1 支持模式

- 顺序播放：按当前队列顺序播放，播放到最后一首后停止。
- 列表循环：按当前队列顺序播放，播放到最后一首后回到第一首继续播放。
- 单曲循环：当前歌曲播放完成后重新播放当前歌曲。
- 随机播放：下一首从当前队列中随机选择，尽量避免连续重复当前歌曲。

### 3.2 页面入口

- 播放页增加播放模式按钮。
- 按钮点击后在四种模式之间循环切换。
- 播放页显示当前模式名称。
- 后续可在“我的”页面补充默认播放模式设置。

### 3.3 状态保存

- 当前播放模式需要本地保存。
- 用户下次打开应用时继续使用上一次选择的播放模式。
- 建议保存到 `SharedPreferences`，和当前收藏、最近播放本地状态保持一致。

### 3.4 验收标准

- 点击播放模式按钮后，模式文案和图标能够正确变化。
- 顺序播放到最后一首后停止。
- 列表循环到最后一首后自动播放第一首。
- 单曲循环时同一首歌曲播放完成后重新开始。
- 随机播放时下一首不是简单按顺序前进。

## 4. 自建歌单功能规划

### 4.1 功能范围

- 创建歌单。
- 修改歌单名称。
- 删除歌单。
- 展示自建歌单列表。
- 进入歌单详情页。
- 向歌单添加歌曲。
- 从歌单移除歌曲。
- 点击歌单内歌曲后按歌单顺序播放。

### 4.2 页面设计

歌单页保留现有两个区域：

- 我喜欢。
- 最近播放。

新增第三个区域：

- 自建歌单。

自建歌单区域包含：

- “新建歌单”按钮。
- 歌单列表。
- 歌单名称。
- 歌曲数量。
- 创建时间或更新时间。

歌单详情页建议使用独立 `Activity`，原因是：

- 详情页需要承载歌曲列表、添加歌曲、删除歌曲等更多操作。
- 使用独立页面比在当前 `PlaylistFragment` 内堆叠状态更清晰。
- 后续如果接入排序、批量管理，也更容易扩展。

### 4.3 添加歌曲入口

建议先实现两个入口：

- 音乐库歌曲项长按或更多按钮：添加到歌单。
- 歌单详情页：点击“添加歌曲”进入本地曲库选择页面。

考虑当前列表项还没有更多按钮，首期可以先用“歌单详情页添加歌曲”的方式实现，降低改动范围。

### 4.4 数据保存

自建歌单属于用户长期数据，需要本地持久化。

建议首期仍使用 `SharedPreferences` 保存，理由：

- 当前项目已有 `UserMusicStateRepository` 管理本地用户状态。
- 数据量小，结构简单。
- 可以更快完成演示版本。

建议保存结构：

- 歌单基础信息：歌单 ID、歌单名称、创建时间、更新时间。
- 歌单歌曲关系：歌单 ID、歌曲 ID 列表。

如果后续老师要求更完整的数据管理，再升级到 SQLite 或 Room。

### 4.5 验收标准

- 可以创建一个新的自建歌单。
- 创建后歌单页能看到该歌单。
- 可以进入歌单详情页。
- 可以向歌单添加本地歌曲。
- 可以从歌单移除歌曲。
- 可以删除自建歌单。
- 退出应用后再次进入，歌单数据仍然存在。

## 5. 定时关闭功能规划

### 5.1 功能范围

- 支持关闭倒计时。
- 到时间后自动暂停当前播放。
- 支持取消定时关闭。
- 支持查看剩余时间。

### 5.2 时间选项

建议首期提供固定时间选项：

- 15 分钟。
- 30 分钟。
- 45 分钟。
- 60 分钟。
- 当前歌曲播放完后关闭。

固定选项比自由输入更适合手机端操作，也更容易演示。

### 5.3 页面入口

建议入口放在播放页：

- 播放页增加“定时关闭”按钮。
- 点击后弹出底部弹窗或普通选择弹窗。
- 用户选择时间后，播放页显示剩余时间提示。

后续可在“我的”页面加入说明或默认选项。

### 5.4 执行逻辑

- 使用 `Handler` 或 `CountDownTimer` 管理倒计时。
- 倒计时结束后调用 `MusicPlayerManager.pause()`。
- 如果用户切换歌曲，定时任务继续有效。
- 如果用户退出播放页但应用仍在运行，定时任务继续有效。
- 如果应用进程被系统杀死，首期不保证定时任务继续执行。

### 5.5 验收标准

- 用户可以设置 15/30/45/60 分钟定时关闭。
- 设置成功后能看到剩余时间。
- 用户可以取消定时关闭。
- 到时间后音乐自动暂停。
- “当前歌曲播放完后关闭”在当前歌曲结束时暂停，不进入下一首。

## 6. 页面调整建议

### 6.1 播放页

新增元素：

- 播放模式按钮。
- 定时关闭按钮。
- 定时关闭剩余时间提示。

现有元素保持：

- 歌曲信息。
- 歌词。
- 收藏按钮。
- 播放、暂停、上一首、下一首。
- 进度条。

### 6.2 歌单页

新增区域：

- 自建歌单列表。
- 新建歌单按钮。

保留区域：

- 我喜欢。
- 最近播放。

### 6.3 音乐库页

可选增强：

- 歌曲项增加更多操作入口，用于添加到歌单。

首期可暂缓，先通过歌单详情页添加歌曲。

## 7. 不纳入本次范围

- 云歌单同步。
- 在线账号登录。
- 在线音乐推荐。
- 歌单分享。
- 后台常驻服务和通知栏播放控制。
- 应用被系统杀死后的定时关闭保证。
- 歌单歌曲拖拽排序。

## 8. 推荐实施顺序

1. 播放模式。
2. 定时关闭。
3. 自建歌单基础数据。
4. 自建歌单页面和详情页。
5. 歌单添加歌曲和播放联动。
6. 最终联调和手机端验证。

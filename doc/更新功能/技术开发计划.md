# 更新功能技术开发计划

## 1. 开发原则

- 不改变当前 `MainActivity + BottomNavigationView + Fragment` 主结构。
- 优先复用现有 Java 类和 XML 布局风格。
- 新增功能保持本地运行，不接服务端。
- 界面文案继续使用简体中文资源文件。
- 首期以可演示、可验收为目标，数据结构保持简单可维护。

## 2. 现有模块复用关系

### 2.1 播放控制

现有类：

- `MusicPlayerManager`
- `PlayerActivity`

需要扩展：

- 播放模式状态。
- 播放完成后的下一首决策。
- 播放模式切换入口。
- 定时关闭任务。

### 2.2 用户状态数据

现有类：

- `UserMusicStateRepository`

需要扩展：

- 保存播放模式。
- 保存自建歌单数据。
- 保存歌单歌曲关系。
- 通知页面刷新。

### 2.3 歌单页面

现有类：

- `PlaylistFragment`

需要扩展：

- 展示自建歌单区域。
- 新建歌单入口。
- 进入歌单详情页。

### 2.4 音乐库数据

现有类：

- `MusicLibraryRepository`
- `Song`

需要复用：

- 按歌曲 ID 查询歌曲。
- 根据歌单保存的歌曲 ID 列表还原歌曲列表。

## 3. 播放模式技术方案

### 3.1 新增枚举

建议新增：

```text
app/src/main/java/com/localmusic/player/player/PlaybackMode.java
```

枚举值：

- `SEQUENCE`
- `LIST_LOOP`
- `SINGLE_LOOP`
- `SHUFFLE`

每个模式提供：

- 模式名称资源。
- 下一个模式。

### 3.2 `MusicPlayerManager` 扩展

新增字段：

- `PlaybackMode playbackMode`
- `Random random`

新增方法：

- `getPlaybackMode()`
- `setPlaybackMode(PlaybackMode mode)`
- `switchPlaybackMode()`
- `hasNextForCurrentMode()`
- `resolveNextIndexOnCompletion()`
- `resolveNextIndexByUserAction()`

播放完成逻辑调整：

- 顺序播放：最后一首播放完成后停止。
- 列表循环：最后一首播放完成后回到第一首。
- 单曲循环：播放完成后重新播放当前歌曲。
- 随机播放：随机选择下一首。

用户点击下一首逻辑：

- 顺序播放：不是最后一首时前进。
- 列表循环：最后一首时回到第一首。
- 单曲循环：建议点击下一首仍按队列前进，避免用户被锁在单曲。
- 随机播放：随机选择下一首。

### 3.3 状态持久化

在 `UserMusicStateRepository` 中新增：

- `KEY_PLAYBACK_MODE`
- `getPlaybackModeName()`
- `setPlaybackModeName(String modeName)`

也可以独立新增 `PlayerSettingsRepository`。考虑当前项目规模，建议先放入 `UserMusicStateRepository`。

### 3.4 播放页 UI

在 `activity_player.xml` 中新增：

- 播放模式按钮。
- 当前模式文字。

在 `PlayerActivity` 中新增：

- 点击按钮切换模式。
- 状态刷新时绑定模式名称。

## 4. 定时关闭技术方案

### 4.1 管理位置

建议放在 `MusicPlayerManager` 内部管理，原因：

- 定时关闭直接控制播放状态。
- 播放页关闭后定时任务仍应在应用进程内有效。
- 其它页面后续也可以读取定时状态。

### 4.2 新增字段

```text
private CountDownTimer sleepTimer;
private long sleepTimerEndAtMs;
private boolean stopAfterCurrentSong;
```

### 4.3 新增方法

- `startSleepTimer(long durationMs)`
- `stopAfterCurrentSong()`
- `cancelSleepTimer()`
- `hasSleepTimer()`
- `getSleepRemainingMs()`
- `isStopAfterCurrentSongEnabled()`

### 4.4 完成歌曲后的处理

如果启用“当前歌曲播放完后关闭”：

- 当前歌曲完成时暂停或停止播放。
- 清除该设置。
- 不进入下一首。

### 4.5 UI 入口

在 `PlayerActivity` 中：

- 新增“定时关闭”按钮。
- 点击弹出 `AlertDialog`。
- 选项：15 分钟、30 分钟、45 分钟、60 分钟、当前歌曲结束后、取消定时。
- 播放状态刷新时显示剩余时间。

### 4.6 风险

- 应用进程被系统杀死后，倒计时不会继续执行。
- 首期不做前台服务，因此这点需要在验收说明中明确。

## 5. 自建歌单技术方案

### 5.1 数据模型

新增模型：

```text
app/src/main/java/com/localmusic/player/model/UserPlaylist.java
```

字段：

- `id`
- `name`
- `songIds`
- `createdAt`
- `updatedAt`

### 5.2 数据持久化

首期建议继续使用 `SharedPreferences`：

- 使用 JSON 保存歌单列表。
- 每个歌单内保存歌曲 ID 列表。
- 通过 `Gson` 序列化和反序列化。

当前项目已经引入 `Gson`，可以直接复用。

新增仓库能力：

- `getUserPlaylists()`
- `createPlaylist(String name)`
- `renamePlaylist(String id, String name)`
- `deletePlaylist(String id)`
- `addSongToPlaylist(String playlistId, Song song)`
- `removeSongFromPlaylist(String playlistId, long songId)`
- `getPlaylistSongs(String playlistId)`

这些方法建议放在 `UserMusicStateRepository`，避免新增多个本地状态仓库。

### 5.3 歌单页扩展

`PlaylistFragment` 新增：

- 自建歌单标题。
- 新建歌单按钮。
- 自建歌单 RecyclerView。
- 空状态提示。

新增适配器：

```text
app/src/main/java/com/localmusic/player/adapter/UserPlaylistAdapter.java
```

列表项布局：

```text
app/src/main/res/layout/item_user_playlist.xml
```

### 5.4 歌单详情页

新增：

```text
app/src/main/java/com/localmusic/player/activity/UserPlaylistDetailActivity.java
app/src/main/res/layout/activity_user_playlist_detail.xml
```

页面功能：

- 显示歌单名称。
- 显示歌曲数量。
- 显示歌单歌曲列表。
- 添加歌曲。
- 移除歌曲。
- 播放歌单内歌曲。

### 5.5 添加歌曲页面

首期建议在歌单详情页内提供“添加歌曲”弹窗：

- 弹窗展示本地歌曲列表。
- 点击歌曲后添加到当前歌单。
- 已存在的歌曲不重复添加。

如果弹窗列表过长，后续再拆成独立选择页。

### 5.6 删除与重命名

首期交互建议：

- 歌单详情页右上角提供操作按钮。
- 操作项：重命名、删除歌单。
- 删除前弹出确认框。

## 6. 开发阶段安排

### 阶段一：播放模式

目标：

- 播放模式可切换。
- 播放完成逻辑按模式执行。
- 播放页能显示当前模式。

涉及文件：

- `MusicPlayerManager.java`
- `PlaybackMode.java`
- `PlayerActivity.java`
- `activity_player.xml`
- `strings.xml` 或新增资源文件

验证：

- 顺序播放。
- 列表循环。
- 单曲循环。
- 随机播放。

### 阶段二：定时关闭

目标：

- 播放页可以设置定时关闭。
- 到时间后暂停播放。
- 可以取消定时关闭。

涉及文件：

- `MusicPlayerManager.java`
- `PlayerActivity.java`
- `activity_player.xml`
- 字符串资源文件

验证：

- 选择固定分钟数后能显示剩余时间。
- 到时间后暂停。
- 取消后不会暂停。
- 当前歌曲结束后关闭能阻止自动下一首。

### 阶段三：自建歌单数据层

目标：

- 可以创建、读取、更新、删除自建歌单。
- 可以向歌单添加和移除歌曲。
- 数据可以本地保存。

涉及文件：

- `UserMusicStateRepository.java`
- `UserPlaylist.java`
- `MusicLibraryRepository.java`

验证：

- 重启应用后歌单仍存在。
- 歌单歌曲 ID 可以正确还原为歌曲列表。

### 阶段四：自建歌单页面

目标：

- 歌单页显示自建歌单列表。
- 可以新建歌单。
- 可以进入歌单详情页。

涉及文件：

- `PlaylistFragment.java`
- `fragment_playlist.xml`
- `UserPlaylistAdapter.java`
- `item_user_playlist.xml`
- `UserPlaylistDetailActivity.java`
- `activity_user_playlist_detail.xml`
- `AndroidManifest.xml`

验证：

- 新建歌单后立即展示。
- 点击歌单进入详情页。
- 空状态文案正确。

### 阶段五：歌单详情和播放联动

目标：

- 可以添加歌曲到歌单。
- 可以移除歌曲。
- 点击歌单歌曲后按歌单队列播放。

涉及文件：

- `UserPlaylistDetailActivity.java`
- `LibraryItemAdapter.java`
- 可能新增歌曲选择适配器或复用现有适配器

验证：

- 歌单添加歌曲后数量变化。
- 移除歌曲后列表刷新。
- 播放歌单歌曲时队列顺序正确。

- 删除正在播放歌曲所在的歌单。

### 7.3 回归测试

- 本地音乐扫描。

- AI 页面入口不受影响。

## 8. 预估改动规模

- 新增 Java 类：3 到 5 个。
- 修改 Java 类：4 到 6 个。
- 新增 XML 布局：2 到 4 个。
- 修改 XML 布局：2 个。
- 新增字符串资源：约 30 条。

整体属于中等规模功能更新，建议按阶段提交和验收，不建议一次性把三块功能全部堆在同一个未验证版本中。

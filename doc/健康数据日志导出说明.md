# 健康数据日志导出说明

本文用于指导使用者在“健康数据页面”或“打卡统计页面”出现问题时，找到应用生成的调试日志，并发送给开发者分析。

## 一、什么时候需要导出日志

如果出现以下情况，请先复现问题，再导出日志：

- 今日步数不显示
- 心率不显示
- 血压录入后页面没有变化
- 打卡统计页面没有数据显示
- 图表为空、数据明显异常
- 页面提示正常，但实际没有拿到数据

## 二、导出前建议先做的事

为了让日志更有分析价值，请按下面顺序操作：

1. 打开应用，进入“健康数据页面”或“打卡统计页面”
2. 复现一次问题
3. 复现后等待 3 到 5 秒
4. 退出当前页面，必要时退出应用
5. 再去手机目录中查找日志文件

## 三、日志保存位置

应用会把日志保存到手机的应用专属外部目录中，常见路径如下：

`内部存储/Android/data/com.Health/files/Documents/health_logs/`

日志文件名格式如下：

`health_debug_年-月-日.log`

例如：

`health_debug_2026-04-22.log`

部分手机上如果 `Documents` 目录不可见，日志也可能位于：

`内部存储/Android/data/com.Health/files/health_logs/`

## 四、如何找到日志

### 方法 1：使用手机文件管理器

1. 打开手机“文件管理”或“文件管理器”
2. 进入“内部存储”
3. 依次进入：
   `Android`
   `data`
   `com.Health`
   `files`
   `Documents`
   `health_logs`
4. 找到最新日期的 `health_debug_*.log` 文件

### 方法 2：连接电脑导出

如果手机文件管理器看不到 `Android/data`，可以：

1. 用数据线连接电脑
2. 打开手机存储
3. 进入：
   `Android/data/com.Health/files/Documents/health_logs/`
4. 把最新日志复制到电脑后发送给开发者

## 五、发送给开发者时建议一并提供

为了更快定位问题，建议同时发送以下信息：

- 日志文件
- 问题发生的大概时间
- 出问题的是“健康数据页面”还是“打卡统计页面”
- 问题现象描述
- 手机品牌和型号
- Android 系统版本
- 问题页面截图

## 六、建议的话术

发送日志时可以附上下面这段说明：

> 我在 `某某页面` 复现了问题，问题发生时间大约是 `几点几分`，现象是 `步数/心率/统计数据不显示`。附件里是日志文件和截图，请帮忙排查。

## 七、说明

- 日志文件会按日期生成
- 建议优先发送当天最新的日志文件
- 如果同一天内多次复现问题，可以把当天的日志都发送过来
